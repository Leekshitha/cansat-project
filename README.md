# CanSat Project

## Atmospheric Data Acquisition and Telemetry CanSat

### Description
This project is a low-cost CanSat developed using ESP32 to collect atmospheric data and transmit it wirelessly to a ground station using the NRF24L01 module.

### Features
- Temperature monitoring
- Humidity monitoring
- Pressure measurement
- Altitude calculation
- Air quality monitoring
- Wireless telemetry using NRF24L01

### Hardware Used
- ESP32
- DHT22
- BMP180
- ADXL345
- MQ135
- NRF24L01
- OLED Display

### Software Used
- Arduino IDE
- GitHub
- C/C++
